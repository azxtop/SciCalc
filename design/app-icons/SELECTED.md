# Selected application icon

The user selected the second refined concept, `06-architectural-sigma.png`: ivory background, graphite sigma and vermilion accent.

Version 0.4.6 translates that artwork into Android vector paths, retaining the silhouette and palette. Adaptive foreground uses 80% of the artwork scale to preserve the diagonal corners under circular launcher masks. The background is #ECE9DF. Android 13 themed icons use a matching monochrome silhouette. Launcher resources are `mipmap-anydpi-v26/ic_launcher.xml` and `mipmap-anydpi-v33/ic_launcher.xml`; the manifest uses the adaptive icon for regular and round icons.

Original concept and exact image-generation prompt remain in this directory; launcher code uses vector resources rather than a raster image.
