# SciCalc

原生 Android 科学计算器。界面和键盘操作参考 CalcES，公式编辑和应用代码独立实现，符号运算采用 Symja。

源码：[azxtop/SciCalc](https://github.com/azxtop/SciCalc) · 下载：[GitHub Releases](https://github.com/azxtop/SciCalc/releases) · 许可证：[GPL-3.0-or-later](LICENSE)

* CALC 在当前公式中逐项代入；SOLVE 求解当前方程，历史保存原公式。

* 带分数、循环小数、指定底数对数、n 次根、连乘、极限、度分秒与矩阵网格均可直接编辑。
* RCL/STO 后按变量键存取；自定义多参数函数、命名矩阵/向量、带频数统计网格和回归。
* 实时结果、连续计算行、逐行格式菜单、结构化公式/图片/LaTeX/MathML 复制，MORE 显示角度、罗马数字、约数与进制详情。
* 相机/图片输入、裁剪、旋转、本地 OCR 与识别结果修改；按本次要求，OCR 暂停对照修改。

* 完整/基础键盘、SHIFT / ALPHA、结构化分数与根式、触摸光标、方向键和撤销。
* 精确/小数结果、DEG / RAD / GRAD、NORM / FIX / SCI / ENG / SI 格式与精度。
* 方程、不等式、微积分、矩阵、向量、统计、概率、进制和函数表。
* 函数、参数、极坐标与隐式曲线；缩放、平移和函数分析。
* 深色描边历史卡片：自然公式、右侧结果、底部日期与模式、删除/复制/重新编辑。升序/降序、本地保存及文本导出。
* 16 个变量的编辑、插入和清除；分别设置按键、等号、结果与错误的声音/振动，10 种皮肤预览、设置和可搜索手册。

按用户要求，单位转换、货币转换、数学公式库、物理公式库、化学方程式及化学原子页面已删除，同时移除快捷入口、相关说明和应用的联网权限。更新时清理这些模块的本地缓存、收藏与草稿。

0.3.2 包含历史页重做与小数精度修复；旧版历史继续可读，未保存日期的旧记录显示“日期未记录”。新记录保存结构化输入、精确值、当时显示的结果、角度、模式与日期。

0.3.3 的工具计算历史保存名称和参数；重新编辑回到参数输入框，复制和导出使用可读内容。矩阵逆、解方程等内部引擎调用不再作为新工具记录的显示公式。

## 0.5.4 连续多指输入性能

- 数字分组排版改为逐段扫描，避免长数字在按键动画期间反复扫描整串。
- 预计算表达式的准备统一延后到停止输入 300 ms 后；连续按键只保留最后一次预计算，等号取消待处理预计算。
- 输入即时保存，已提交历史在计算、编辑历史和离开页面时保存，按键不再重复序列化全部历史。
- 长输入的光标在末尾时直接使用已测宽度，减少重复绘制；同键重叠、释放顺序、长按和滑出取消继续采用已对照的规则。

## 0.5.3 稳定后的主键盘布局

- 原版启动后顶部占位区会重新测量；无操作、公式不变时也会发生位置变化，并非由公式是否为空决定。
- 主键盘逐行按原版稳定后的控件尺寸和位置校准，工具栏上移 28 逻辑像素，方向键及触摸矩形同步更新。
- 顶部留白继续并入本版输出框，输出框底部随工具栏上移，公式裁剪、结果点选和滚动使用对应的新边界。
- 本版直接采用稳定布局；未模拟原版顶部占位区加载时长及启动期间的跳动。

## 0.5.2 按键点击范围

- 主键盘的触摸矩形按原版同机控件边界校准，覆盖可见轮廓外的少量背景；键间空隙仍不触发。
- 按下后轻微滑出仍可触发；移动超过系统容差后取消，即使滑回也不输入。松手不再用可见轮廓重复判断。
- 方向键、SHIFT、副功能和长按删除使用校准后的范围；按键外观保持原样。

## 0.5.1 积分与导数的返回逻辑

- 积分/导数窗口和说明窗口点击外部关闭，并吃掉本次触摸，避免同时触发底下的 MODE、SHIFT 或光标操作。
- 说明留在主屏下半部；系统返回直接关闭，不再重新打开上一级积分/导数菜单。
- 说明中的“打开积分菜单 / 打开导数菜单”替换当前窗口，重复进入不叠加返回层级。

## 0.5.0 键盘尺寸与输出框

- 按原版同机截图恢复主键盘的按键高度、行距和位置，另校准方向键外框。顶部留白并入输出框，输出框从 520 增至 670 逻辑像素高。
- 绘制与每个指针的按下、移动、松开共用键盘坐标映射；按键波纹、长按和拖出取消随新位置工作。
- 输出框的绘制裁剪、结果点选、光标和滚动区域同步扩展；皮肤预览使用同一布局。

## 0.4.9 长公式显示修复

- 长公式的光标位置测量改为离屏录制，屏幕只绘制一次公式，消除长数字重叠。
- 结果区保留三点按钮空间，超长结果裁剪在文字区域内，避免覆盖按钮。
- 长数字、长分数、光标移动和后台硬件资源回收实机检查通过；升级保留当前公式、结果、历史和设置。详见 VALIDATION.md。

## 0.4.8 多指、反馈与手势

- 每根手指独立处理按键，按松手顺序输入；SHIFT/ALPHA 在松手时生效，同键多指、拖出取消和系统取消均明确处理。
- 黄色副功能长按约 300 ms；DEL/方向键约 400 ms 开始重复、每 200 ms 触发，按固定时间点调度，松手仍执行最后一次。实际临界点受设备事件队列影响。
- 按键、结果、错误的振动按原版实机波形实现，包含 17 种选择；强度调脉冲时长，重复间隔保持不变。等号属于键盘振动开关。
- 73 个音效选择（含 None），使用 72 个独立生成的本地 WAV；预载播放，支持删除、清除、等号、结果、错误分别设置。音色不是原版采样。
- 抽屉声音图标短按切换、长按打开设置；设置开关原地更新，声音/振动可横滑，选择面板保持打开并预览。拖动强度/音量滑块不会翻页。
- 点按结果数字打开格式，长按公式或结果打开对应菜单；支持粘贴、分享、结构化文本/LaTeX/MathML 复制、图片导出、创建函数及程序编辑器。
- 修正矩阵选框与绘图按钮的拖动误触、双指缩放到单指拖动的跳变；失焦、后台和页面切换取消未完成触摸。
- 本轮 52 个单元测试、87 项实机状态/反馈检查通过，证据见 VALIDATION.md。覆盖主要自绘触摸路径，不据此宣称所有模式与子页面已整体达到 1:1。

- 默认 NORM 11、等宽显示字体参考原版，已有显式设置保留。反三角函数等机器小数结果按显示精度舍入，后续计算保留引擎值；分数、根式和大整数仍保留精确显示。

## 0.4.6 应用图标

采用用户选定的米白求和图标：米白背景、深灰 Σ 与砖红尾标。以矢量资源实现，适配圆形/圆角桌面图标，提供 Android 13 单色主题图标。

## 0.4.5 绘制缓存恢复

修复后台返回或硬件资源回收后键盘、完成计算行消失：绘制前核对 RenderNode.hasDisplayList()；失效时重新录制键盘或从保留的 Picture 恢复结果节点。保留公式解析与滚动缓存优化，以及 0.4.4 的历史容量。

## 0.4.4 历史容量

- 默认保存上限从 100 条增加到 1,000 条。旧版低于 1,000 条的设置自动提升，原记录保留。
- 设置 → 格式 → 历史记录上限，可选择 1,000 / 3,000 / 10,000 条。普通计算、工具计算与模式计算使用同一个上限；超过上限时移除最早的记录。

## 0.4.3 交互与绘制优化

- AC 按状态清除：编辑中清当前式子；完成计算后第一次 AC 进入新的空输入并保留屏幕计算，空输入时再按 AC 清屏。SHIFT＋AC、长按 AC 直接清屏，长期历史、Ans、PreAns、变量不受影响。
- RCL/STO 与 CALC 状态先退出再清输入。恢复空光标、分隔线及 MORE 的状态切换。
- 按键采用变暗后淡出的反馈；拖出按键取消点击，长按副功能与连续删除保留。
- 抽屉滑入/滑出、背景渐暗、菜单图标旋转、左边缘滑出、跟手拖回和短拖回弹；MODE、内嵌子窗口淡入淡出，完整页面从右侧进入并向右返回。
- 结果区与 MODE 列表加入惯性滚动，拖动不再误点结果菜单。公式、显示结果、键盘和已完成计算缓存绘制，滚动只绘制可见记录。
- 同设备、30 条分数计算、12 次相同 450 ms 拖动：帧耗时中位数约 614→11.5 ms；Android 本次掉帧统计 100%→0.12%。这是该测试场景的数据，不代表全部界面或设备。

## 0.4.2 对照修正

- 结果区三点打开对应记录的结果格式浮层，实时预览也可打开；支持小数、循环小数、分数、带分数、度分秒、整数质因数分解。各结果独立取值，不改变 Ans、原式或历史。
- 浮层可展开、切换宽度和关闭。长按预览打开分享、文本/LaTeX/MathML 复制、图片导出及程序编辑器入口。
- 结果记录之间增加细灰分隔线；已完成的最后一条记录不显示额外空光标或底部分隔线。滚动范围按内容限制。
- CALC/SOLVE 的空输入提示改为参考文字、灰色对话框及“确定/取消”顺序，确认进入使用说明。CALC 内联变量提示统一为 x=?。
- 积分、导数和极限改为内嵌编号列表、原版菜单文字、公式预览和独立信息按钮，连接实际模板与数值积分方法。
- Logₓy 上方求和/连乘改为独立绘制的细线数学符号，避免设备字体导致符号粗细、比例变化。

## 使用

三横杠打开菜单，MODE 打开计算模式。工具栏的历史图标直接打开计算历史。
分数键把前面的数字或模板作为分子，光标进入分母。方向键可以进入/退出模板；点公式可以移动光标。
主计算器三角函数遵循 DEG / RAD / GRAD；图形和脚本使用弧度。矩阵可用 ALPHA → 4 插入模板，或从 MODE → 矩阵编辑命名数据。MODE → 统计 → DATA 使用主键盘编辑网格，MODE 返回统计菜单。
历史长公式可横向滑动；点公式或编辑图标恢复输入。复制图标支持公式、结果或整条记录。导出打开系统分享面板，由用户选择保存或分享目的地。

## 当前边界

这是开发测试版本，**尚不宣称所有界面与功能达到 CalcES 1:1**。0.4.1 修正了自然公式的根号轮廓、黑色占位框和分数间距，完成计算后保留输入字号，并去掉 PRO 键。设置分为六个标签页；函数、矩阵、向量、统计、常数、复数、分布与数字格式采用参考页面布局。基数使用专用键盘，数字表使用五步输入，多项式和方程组使用系数表；原版基线与本版验证见 [KEY_FUNCTION_AUDIT.md](KEY_FUNCTION_AUDIT.md)、[VALIDATION.md](VALIDATION.md)。子页面、字体、图标、状态锁定规则与原版仍有差异；函数目录未逐项进行全参数边界验证。
OCR 使用本地 Latin 文本模型。清晰的单行算式已验证；二维分数、复杂上下标、手写和多行排版需检查识别结果，尚不能保证与原版数学 OCR 的识别能力相同。
绘图参数/极坐标范围为 0~2π，隐式图使用数值网格，区间极值为采样与局部优化结果。
脚本使用 Symja 表达式语言，单次最多 8 秒；脚本状态与主计算器变量隔离，草稿和命名脚本保存在本机。
数学引擎无法化简的表达式会保留原式。Android 12+，本次测试机 Android 14。

## Build

需要 JDK 17、Android SDK（Android 36 平台及相应构建工具），运行要求 Android 12 及以上。Android Studio 可直接导入本仓库；Gradle Wrapper 已包含在源码中。

克隆仓库：

```sh
git clone https://github.com/azxtop/SciCalc.git
cd SciCalc
```

在根目录创建 `local.properties`，设置本机 SDK 路径，例如 Windows 使用 `sdk.dir=C:/Android/Sdk`；也可配置 `ANDROID_HOME`。该文件不提交到 Git。然后执行：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest --console=plain
```

Linux / macOS：

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest --console=plain
```

APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。预编译开发测试包从 [Releases](https://github.com/azxtop/SciCalc/releases) 下载；使用 debug 签名，不含发布私钥。自行构建的包与已安装包签名不一致时无法直接覆盖安装。

`tools/touchprobe` 是可选的 ADB 触摸测试辅助模块，`tools/generate_feedback_audio.py` 可重新生成原创按键音效。构建与实机记录见 [VALIDATION.md](VALIDATION.md)、[UI_REVIEW.md](UI_REVIEW.md)。本地截图、设备备份、计算历史、构建缓存和诊断快照不包含在公开仓库中。
